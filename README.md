# AURA Professional Smartphone Website

A premium static website for the AURA Class XII Business Studies smartphone-company project.

## Included
- AURA logo and three phone models
- Product comparison table
- Detailed technology section
- AURA OS / AI positioning
- Camera section
- AURA Ultra deep-dive
- Brand ambassadors
- Campaign gallery using supplied promotional artwork
- Ecosystem section
- FAQ
- Newsletter demo
- Interactive demo shopping bag/modal
- Animated particle field, cursor aura, glowing rings, gradients and hover effects
- Responsive desktop/tablet/mobile layout

## GitHub Pages
Keep `index.html` at repository root and `assets/` beside it. The intended repository name for the top-level site is `auramobile.github.io`.
